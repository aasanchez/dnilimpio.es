# Articles

Each file in a language folder is one article on the site. The README in the repository root
explains how to write and publish one (section "Articles"). In short:

- Put the file in the folder of its language: `es/`, `en/`, `ca-es-valencia/` and so on.
- The file name is the address: `es/como-tapar-el-dni.md` becomes `/articles/como-tapar-el-dni`,
  and `en/how-to-cover-your-id.md` becomes `/en/articles/how-to-cover-your-id`.
- Start the file with the front matter (title, description, type, date). Use `##` for headings.
- No HTML inside the Markdown, and only relative links to the site's own pages.
- Images go in the same folder (PNG, JPEG, WebP or AVIF). Never a photo of a real document.
- The text of the articles is licensed under CC BY-SA 4.0.
